## N-grams

N-grams are contiguous sequences of n items from a given sample. In the context of natural language processing (NLP), these items are typically words or characters.

### Example
In the sentence "I love natural language processing,":

- word-level 1-grams (unigrams) would be "I," "love," "natural," "language," and "processing."
- word-level 2-grams (bigrams) would be "I love," "love natural," "natural language," and "language processing."
- word-level 3-grams (trigrams) would be "I love natural," "love natural language," and "natural language processing." and so on.

Similarly, character-level n-grams can be generated by considering sequences of characters instead of words. For example,  
- the character-level 2-grams (bigrams) for the word "love" would be "lo," "ov," and "ve."

## N-gram models
N-gram models are a type of probabilistic language model that predicts the next item in a sequence based on the previous n-1 items. Unlike rule-based models like Eliza, n-gram models learn patterns from large corpora of text data and can generate more contextually relevant responses. Given a sequence of words or characters, an n-gram model finds the probability of each possible next word or character based on the preceding n-1 words or characters, and selects the most likely one to generate a response.

Though n-gram models are relatively simple compared to the current neural network-based models, they play a significant role in the history of NLP. They are often used now as a baseline for evaluating more complex models and can still be effective in certain applications, especially when computational resources are limited. 

### How it works
The process of creating and using n-gram models involves several steps:
1. **Data Collection**: Gathering a large corpus of text data.
2. **Preprocessing**: Cleaning and preparing the text data for analysis.
3. **N-gram Generation**: Extracting n-grams from the preprocessed text.
4. **Model Training**: Calculating the probabilities of each n-gram based on their frequencies in the training data.
5. **Prediction**: Using the trained model to predict the next item in a sequence based on the previous n-1 items.

#### Example
For example, given the word "bananas", a trigram character-level model would generate the following trigrams: "ban," "ana," "nan," "ana," and "nas." For each trigram, the first two characters, knows as context, are used to predict the next character.

During training,

| Step | Window (size 3) | context (length 2) |	char (length 1) |
|------|-----------------|--------------------|-----------------|
1 | "ban" | "ba" | 'n'
2 |	"ana" |	"an" |	'a'
3 |	"nan" |	"na" |	'n'
4 |	"ana" |	"an" |	'a'
5 | "nas" |	"na" |	's'

A trained trigram model would learn the probabilities of each character following a given context. One way to do this is by using a frequency count of the occurrences of each character following a given context in the training data. For example, 
{
    "ba": {"n": 1},
    "an": {"a": 2},
    "na": {"n": 1, "s": 1}
}

and using this it can calculate the probabilities of each character following a given context. For example, the probability of 'n' following 'ba' would be 1/1 = 1.0, the probability of 'a' following 'an' would be 2/2 = 1.0, and the probability of 'n' following 'na' would be 1/2 = 0.5, while the probability of 's' following 'na' would also be 1/2 = 0.5.

### Smoothing in N-gram models
Smoothing is a technique used in n-gram models to handle the problem of zero probabilities for unseen n-grams in the training data. When an n-gram is not present in the training data, the model assigns it a probability of zero, which can lead to poor performance when generating text. Smoothing techniques adjust the probabilities of n-grams to account for unseen events, ensuring that the model can still generate reasonable predictions even for n-grams that were not observed during training. Common smoothing techniques include Laplace smoothing, Good-Turing smoothing, and Kneser-Ney smoothing.

### How to run the N-gram model
To run the N-gram model, navigate to the `models/02_ngram` directory and run the following command:
```bash
python train.py
```
Default is a 4-gram model. You can change it by passing arguments to the script. For example, `python train.py 3` will train a trigram model. The model will be trained on the [`tinyshakespeare.txt`](../../data/tinyshakespeare.txt) dataset and saved as `ngram.pkl`. You can also change the dataset by modifying the `DATA_PATH` variable in `train.py`.

To generate text using the trained model, run the following command:
```bash
python infer.py
```
Default `seed` is "ROMEO:" and `length` is 400. You can change these values by passing arguments to the script. For example, `python infer.py "JULIET:" 500` will generate 500 characters of text starting with "JULIET:". The `seed` is the initial string to start the generation and `length` is the desired length of the generated text.
